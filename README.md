# Himanshu Mandiya — Portfolio

A single-page, responsive portfolio built with semantic HTML5, CSS3 and vanilla JavaScript.

## Deploy
Upload this folder to GitHub Pages, Netlify, or Vercel as a static site.

## Before publishing
- Add a professional headshot in place of the HM placeholder.
- Add a GitHub URL if you want a GitHub icon/link.
- For a true server-side contact form, connect the form to Formspree, Netlify Forms, or an API.
- Replace/confirm the resume PDF if you update your CV.
